## 網址

- GitHub Pages：https://lachusi21.github.io/yilan-2026-election/
- Cloudflare Pages：https://yilan-2026-election.pages.dev

## 部署

兩個平台都會在 push 到 `main` 分支時自動更新，不需要額外設定：

| 平台 | 方式 |
|---|---|
| GitHub Pages | 由 `main` 分支根目錄直接發布 |
| Cloudflare Pages | Cloudflare 透過 GitHub App 連接此 repo，偵測到新 commit 就自動部署（無建置指令，輸出目錄為根目錄） |
